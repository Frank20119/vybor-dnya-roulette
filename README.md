# Выбор дня

Небольшая интерактивная рулетка с реальными названиями сервисов и игр в стиле Material Design.

Это статический сайт без зависимостей: откройте `index.html` в браузере или опубликуйте папку через GitHub Pages. Логотипы подгружаются из Simple Icons; при отсутствии сети интерфейс показывает буквенные заглушки.

Важно: это демонстрационный мини-интерфейс. Он не управляет подписками и не предполагает денежных выплат — показанные суммы являются игровыми баллами.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub и отправьте в него эти файлы.
2. В настройках репозитория откройте **Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.
4. GitHub выдаст публичную ссылку в формате `https://<ваш-логин>.github.io/<имя-репозитория>/`.
