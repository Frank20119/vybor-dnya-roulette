# Выбор дня

Небольшая интерактивная рулетка с каталогом обычных сервисов и игр в стиле Material Design.

Это статический сайт без зависимостей: откройте `index.html` в браузере или опубликуйте папку через GitHub Pages. Логотипы подгружаются из Simple Icons; при отсутствии сети интерфейс показывает буквенные заглушки.

После каждого решения сервис убирается из последующих прокруток. Баланс, решения пользователя и состояние демонстрационной витрины хранятся только в `localStorage` браузера.

## Витрина ограниченных сервисов

Витрина использует публичные сообщения об ограничении доступа к LinkedIn, Viber, Signal, Discord, Facebook и Instagram. У каждой карточки есть ссылка на источник: Мосгорсуд, Генпрокуратура или сообщение Роскомнадзора, переданное СМИ. Уровни I–V и цены — авторская игровая шкала, а не правовая оценка, штраф или реальный способ разблокировки.

Важно: это демонстрационный мини-интерфейс. Он не управляет подписками, не принимает деньги и не снимает ограничения доступа к каким-либо сервисам.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub и отправьте в него эти файлы.
2. В настройках репозитория откройте **Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.
4. GitHub выдаст публичную ссылку в формате `https://<ваш-логин>.github.io/<имя-репозитория>/`.
